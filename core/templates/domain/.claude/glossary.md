# Glossary

The glossary holds the domain's Vocabulary rows and the domain's rules on
instruction text. `clean-prose` reads it after its own text.

## Domain content

## Vocabulary

**This table extends the Vocabulary of `clean-prose` §5**, and §5's rules
bind every row.

| Term | Means | Banned synonyms |
| --- | --- | --- |
| vault | the folder in `~/Documents` that the `vault` key of `domain.json` names, which Obsidian opens as a vault | notes folder, Obsidian folder |
| vault config | `obsidian/` at the domain's root: the default Obsidian config, which the folder step copies into the vault's `.obsidian/` | Obsidian settings, graph config |
