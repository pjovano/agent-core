# Glossary

Each term names one concept. Use the term, never a word of its Not column.

| Term | Means | Not |
| --- | --- | --- |
| record | one fact the user gives, kept as one file of the ledger | entry, item |
| ledger | the directory that holds every record | store, archive |
| record name | the filename the record name rule gives a record | slug |
| registry | the external service that confirms a record title | index |
